# Exchange Exchange is a web platform that allows users to exchange products they no longer need with other users. ## Project Idea The platform provides a simple way for users to list items they no longer need and exchange them for other useful products. ## Features - User-friendly web interface - Add and manage products - Upload product images - Browse available products - Send exchange requests - Manage exchange requests ## Technologies Used - Python - Flask - SQLite - HTML - CSS - JavaScript ## Purpose The project aims to encourage reuse and exchange of products instead of letting useful items go to waste.
